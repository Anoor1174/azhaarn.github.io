Invisible Strings: Detecting Proxy Bias in Machine Learning Models
Designing synthetic datasets with planted proxy variables (e.g. postcode, job title) that encode protected attributes, to test whether models trained without those attributes still reproduce bias. Building a proxy-bias detector in Python and evaluating it against known ground truth across varying proxy strengths.
